# Text Kit

Учебный набор функций: работа со строками, датами, числами и проверка
введённых данных (почта, телефон, пароль). Программа печатает примеры
работы всех функций.

## Структура проекта

```
text-kit/
├── app/
│   ├── __init__.py
│   ├── main.py              только точка запуска: примеры данных и main()
│   ├── utils/               мелкие функции, пригодятся в любом проекте
│   │   ├── __init__.py
│   │   ├── text.py          clean_spaces, shorten, initials, slug
│   │   └── dates.py         parse_date, format_date, is_weekend, days_between
│   └── services/            правила этого проекта
│       ├── __init__.py
│       ├── statistics.py    average, median, spread, count_values
│       └── validation.py    is_email, normalize_phone, is_phone, password_problems
├── tests/                   19 проверок unittest
│   ├── test_dates.py
│   ├── test_statistics.py
│   ├── test_text.py
│   └── test_validation.py
└── README.md
```

## По какому признаку разделены модули

Функции разложены по теме, с которой работают: строки, даты, числа и
проверка данных. Строки и даты — общие инструменты без правил проекта,
поэтому они в `app/utils/`. Расчёты по оценкам и проверка почты, телефона
и пароля — правила именно этой программы, они в `app/services/`.
`validation.py` импортирует `clean_spaces` из `app/utils/text.py`:
сервис может пользоваться утилитами, но ни один модуль не импортирует `main`.
В `dates.py` есть `from datetime import date`, в остальных модулях
этого импорта нет — он им не нужен.

## Запуск

Из корня проекта (папка `text-kit`):

```
py -m app.main
py -m unittest discover -s tests -v
```

На macOS / Linux — `python3` вместо `py`.
