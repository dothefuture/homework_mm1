# Cafe Report

Программа читает заказы кофейни из файла `data/orders.csv` и печатает отчёт:
количество заказов, выручку, средний чек и суммы по официантам.

Внешних библиотек нет, нужен только Python 3.10 или новее.

## Структура проекта

```
cafe-report/
├── app/                 код программы (пакет)
│   ├── __init__.py
│   ├── main.py          точка запуска: читает заказы и печатает отчёт
│   ├── services/        правила проекта: расчёты по заказам и сборка отчёта
│   │   ├── __init__.py
│   │   ├── orders.py    чтение CSV, выручка, средний чек, суммы по официантам
│   │   └── report.py    строки готового отчёта
│   └── utils/           мелкие вспомогательные функции
│       ├── __init__.py
│       ├── money.py     копейки → рубли, запись суммы строкой
│       └── text.py      имена и выравнивание колонок
├── data/                данные, отдельно от кода
│   └── orders.csv       заказы за смену
├── docs/                описание проекта
│   └── about.md
├── tests/               проверки (unittest)
│   ├── test_orders.py
│   └── test_report.py
├── .gitignore           что не попадает в Git: .venv, __pycache__, .env
├── requirements.txt     список зависимостей (внешних пакетов нет)
└── README.md
```

Из архива удалены: кеш `orders.cpython-311.pyc`, служебный `.DS_Store`,
черновик `заметки.txt` и старая версия `main_старая_версия.py`.
Файл `.env` с токеном остался только на моём компьютере: он в `.gitignore`.

## Запуск

Команды выполняются из корня проекта — из папки `cafe-report`.

```
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m app.main
py -m unittest discover -s tests -v
```

На macOS / Linux: `python3 -m venv .venv`, `source .venv/bin/activate`,
дальше `python3` вместо `py`.
